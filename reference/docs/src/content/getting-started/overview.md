# Overview

Lumra is organized around small, composable runtime packages. These reference docs are designed to stay close to the source and make implementation details easy to scan.

![Lumra abstract grid](/content-assets/lumra-grid.svg)

## What you will find

- Clear entry points for runtime, tools, and UI packages.
- Practical setup notes that map directly to monorepo packages.
- Concise implementation guides for common integration paths.

## Design goals

The documentation should be fast, minimal, and readable in both light and dark mode. Each page should prefer concrete examples over broad explanation.
