# `@lumra/tui`

Terminal UI component library for Lumra. Built on [Ink](https://github.com/vadimdemedes/ink) — the React renderer for CLIs.

Uses [InkUI](https://github.com/kamlesh723/InkUI) as the component system — a shadcn/ui-style copy-paste component library for Ink. Add components with:

```sh
bunx @inkui-cli/inkui add spinner badge table select
```
